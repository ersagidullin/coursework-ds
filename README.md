# coursework-ds

## Развертывание приложения

### 1. Склонируйте репозиторий локально

```bash
git clone <URL_репозитория>
cd <название_папки_проекта>
```

### 2. Создайте файл `.env`

В корне проекта создайте файл `.env` и добавьте в него следующие переменные окружения:

```env
DATABASE_URL=postgresql://github_user:github_password@postgres:5432/github_research
GITHUB_TOKEN=Your_GitHub_Token
```

### 3. Запустите проект через Docker Compose

```bash
docker compose up --build
```

## Что произойдет при запуске

После запуска будут автоматически подняты и настроены следующие сервисы:

1. PostgreSQL база данных
2. ETL-приложение для сбора и обработки данных
3. Metabase для визуализации данных

Metabase будет доступен по адресу:

```text
http://localhost:3000
```

## Правила работы с репозиторием

### 1. Создание Pull Request

* Перед созданием PR необходимо синхронизировать ветку с `main`
* Один Pull Request должен соответствовать **одной задаче**
* В поле **Assignee** указывается тот, кто проводит ревью
* **Merge Pull Request** выполняет Assignee после успешного прохождения проверки

### 2. Именование Pull Request и веток

Название должно соответствовать:

* название задачи на английском языке
* все буквы в нижнем регистре
* слова разделяются символом `_`

**Примеры**

```
add_get_repository_endpoint
update_api_response_format
```

### 3. Работа в отдельных ветках

* Разработка ведется в отдельной ветке
* Ветка создается от актуальной `main`
